### 1.2 购买按钮状态机（`updateButtonStatus`，每秒轮询）

```js
const t = parseInt(item.buyTime || item.buyTime)
const e = Date.now()
if (item.isSoldOut)              { btnValue = '已售罄';  btnClass = 'sold-out' }
else if (t < e)                  { btnValue = '立即购买'; btnClass = 'hot-sale'  }
else {
  const gap = t - e
  const h = Math.floor(gap / 36e5).toString().padStart(2, '0')
  const m = Math.floor(gap % 36e5 / 6e4).toString().padStart(2, '0')
  const s = Math.floor(gap % 6e4 / 1e3).toString().padStart(2, '0')
  btnValue = `${h}:${m}:${s}`; btnClass = 'countdown'
}
```

优先级：**售罄 > 已开放 > 倒计时**。倒计时归零后自动切为「立即购买」。

### 1.3 数量弹窗与下单

```js
// countdown / sold-out 状态点击无效，直接 return
openQuantityModal() {
  if (btnClass !== 'countdown' && btnClass !== 'sold-out') {

  createPrimaryOrder({ iid, quantity })   // POST order/primary
    .then(res => {

```

**关键**：接口返回的 `data` 直接就是 `orderId`（字符串），不是对象。

## 二、购买链路（订单 → 支付 → 完成）

### 2.1 订单类型（7 种）

| 类型名 | `type` 值 | 说明 | 接口 |
|--------|-----------|------|------|
| 常规订单 | `10` | 一级市场首发 | `POST order/primary` |
| 申购订单 | `11` | 申购 | — |
| 市场订单 | `20` | 二级市场买入 | `POST order/secondary` |
| 批量订单 | `21` | 批量购买 | `POST order/secondary/batch` |
| 求购订单 | `22` | 求购（挂单等成交） | `POST order/secondary/apply` |
| 委托订单 | `23` | 委托卖单 | `POST order/secondary/trust` |
| 转售订单 | `40` | 转售 | `POST nft/sell/up` |

### 2.2 订单状态机

```
0 待支付 ──支付成功──> 3 已完成
   │  └──支付超时(endPayTime 到期)──> 自动关闭
   ├──用户取消(cancelOrder)──> 2 已取消
   └──退款──> 4 已退款
1 进行中（委托/求购/申购的「中」态）
```

状态文案映射：
```js
{ 0: '待支付', 1: '进行中', 2: '已取消', 3: '已完成', 4: '已退款' }
```

**特殊规则**（`type === 22 || type === 23` 即求购/委托单，且 `status === 3`）：
| 条件 | 显示 |
|------|------|
| `quantity === itemQuantity` | 已完成 |
| `itemQuantity === 0` | 已全部退款 |
| 其他 | 已部分退款 |

### 2.3 二级市场下单的 5 种形态

| 操作 | 接口 | 参数 |
|------|------|------|
| 直接买入某条挂单 | `POST order/secondary` | `{ nftId }` |
| 快速购买（自动取最低价） | `POST order/secondary/quick` | `{ iid }` |
| 批量购买 | `POST order/secondary/batch` | `{ iid, unitPrice, quantity, payWay: 1 }` |
| 求购（挂求购单） | `POST order/secondary/apply` | `{ iid, unitPrice, quantity }` |
| 委托（挂委托卖单） | `POST order/secondary/trust` | `{ iid, unitPrice, quantity }` |

**单位换算**：`unitPrice = 100 * price`（前端输入单位为**元**，接口收**分**）。

### 2.4 出售流程（需二次密码）

```js
// 1. 选择 NFT，校验 status===1（出售中）则拦截
selectNft(row) {
  saleNftBody.nftId = row.nftId
  uni.showModal({
    content: '确定出售吗？',
    success: ({ confirm }) => {
      if (confirm) {
        if (row.status === 1) return showToast('当前藏品出售中')
        hideNftPopup()
        showPwdPopup()      // 打开 6 位数字密码弹窗
      }
    }
  })
}

// 2. 输满 6 位自动提交（watch 监听 secondPassword）
watch: {
  'saleNftBody.secondPassword'(v) {
    if (v && v.length === 6) this.saleNftToNeedOrder()
  }
}

saleNftToNeedOrder() {
  const body = {
    orderId: saleNftBody.orderId,
    nftId: saleNftBody.nftId,
    secondPassword: encrypt(saleNftBody.secondPassword)  // RSA 加密
  }
  sellNeed(body).then(res => {
    res.status && (showToast('出售成功'), 刷新求购列表)
  })
}
```

## 三、前置校验

### 3.1 认证拦截

全站统一：`code === 11111` 表示未认证，前端清理 token 并跳 `/pages/authorize/signin`。

出现在以下位置：
- 藏品详情页下单时（`createPrimaryOrder` 返回 11111）
- 二级市场 4 类下单（`createSecondary*Order` 返回 11111）
- 钱包页、订单列表、我的 NFT 列表（`getNftList` 返回 11111 直接跳登录）

### 3.2 实名认证

存在接口 `POST /passport/realName`（对应页面 `/pages/my/realName`），
配套 `PUT /passport/secondPassword` 设置二次密码（出售时强制验证）。

**注意**：原站前端**未**在购买按钮处做 18 岁 / 实名认证的前端拦截，
该限制由后端在下单接口层校验（前端不预判）。复刻时保持一致——不在前端加拦截。

## 五、发售日历页（`digitalAlbum`）

`GET /nft/digitalAlbum/calendar?pageNo=1&pageSize=10`

- 时间轴布局：年份水印 `absolute top:-2.625rem` + 卡片区 `border-left: dashed`
- `timeFormat(v, flag)`：`'Y'/'m'/'d'`；`> 1e11` 视为毫秒否则秒
- `remainText`：`X天XX时XX分XX秒`，用 `serverTime + remain` 推算截止时间
- 点击卡片 → `/pages/market/info?iid=<item.id>`
- **当前线上返回 `code: 11111`（未认证）→ 显示「暂无藏品」空态**，这是真实状态

## 六、复刻要点清单（踩坑备忘）

| # | 要点 | 说明 |
|---|------|------|
| 1 | **金额单位是分** | `price: 388` → ¥3.88，展示需 `amountFormat(v) = (v/100).toFixed(2)` |
| 2 | **下单入参单位是分** | 前端输入元 → 提交 `unitPrice = 100 * price` |
| 3 | **下单返回 data 直接是 orderId** | 不用解构对象 |
| 4 | **时间戳是毫秒字符串** | 需 `parseInt` 后比较 |
| 5 | **`code === 11111` 是未认证** | 不是 HTTP 401，需在响应拦截器里判断 body.code |
| 6 | **售罄优先级最高** | `isSoldOut` 判断在倒计时之前 |
| 7 | **countdown/sold-out 时数量弹窗不可开** | `openQuantityModal` 直接 return |
| 8 | **二次密码输满 6 位自动提交** | watch 监听长度，不是点确认按钮 |
| 9 | **前端不做 18 岁/实名拦截** | 原站没有，复刻也不加 |
| 10 | **批量购买固定 `payWay: 1`** | 求购/委托/批量下单的 payWay 硬编码 |
| 11 | **rpx 需手工换算** | `1rpx = 1/32 rem = 0.52px`（390px 视口） |
| 12 | **`.stage` 类元素需 `box-sizing: content-box`** | 原站未声明 box-sizing，会被全局 reset 覆盖 |
