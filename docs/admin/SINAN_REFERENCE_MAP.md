# 司南后台提示词 → 臻海后台 参考映射

> 参考源：`司南后台提示词！！！.txt`（17 模块 / 209 接口 / Element Plus + Vue3 TS + ThinkPHP 8.1 + BuildAdmin）
> 结论：**借鉴业务闭环的「设计思路」，照搬会造成大量无法落地的空壳模块。**
> 依据：源站 `h5.shengtai.cyou` 仅有 42 个 GET/POST 端点，且经核实**不存在**转赠、优先购、资格购、空投等概念。

## 一、能力覆盖度实测（决定哪些能搬）

| 司南概念 | 源站端点 | C 端证据 | 能否做 |
|---|---|---|---|
| 寄售挂单 / 成交 | `GET /nft/secondary/sell|sold|apply|trust` | 有 | 可做 |
| 合成 | `GET /item/merge`、`/item/merge/{id}` | 有 | 可做（只读监控） |
| 盲盒 | `GET /nft/box/open` | 有下发口，无独立库存表 | 受限，需确认 |
| 抽奖 | `GET /activity/lottery/{id}` | 有 | 受限 |
| 签到 | `GET /activity/sign` | 有 | 受限 |
| 订单 | `GET /order`、`/order/{id}` | 有（仅 2 条） | 可做 |
| 钱包流水 | `GET /user/wallet`、`/wallet/log`、`/wallet/hfpay` | 有 | 可做 |
| **转赠** | — | `docs/api.md` 命中 0 次 | **无对象** |
| **优先购** | — | 命中 0 次 | **无对象** |
| **资格购** | — | 命中 0 次 | **无对象** |
| **独立空投** | — | 命中 0 次 | **无对象** |

司南 3.1～3.3 节（库存配额、资格购、优先购）占整份文档约 30% 篇幅，
**这三大闭环在源站无任何落点**。照搬等于做 30% 永远为空的功能。

## 二、可直接借鉴的部分（已纳入设计）

这些是**与具体业务无关的通用后台工程纪律**，价值最高：

| 司南条目 | 借鉴方式 |
|---|---|
| 第十章 高风险操作统一规范 | 二次弹窗 + 原因 + 管理员密码，已纳入 bulk 操作设计 |
| 3.7 实名信息安全 | 手机号 / 姓名 / 身份证三级脱敏；查看完整值需二次密码 + 记审计日志 |
| 3.9 审计日志全覆盖 | `admin_operation_logs` 表已建成，写操作全量留痕 |
| 第五章 权限体系 | 后端返回 `menus` + `permissions`，Pinia 存储；401 跳登录 / 403 弹窗 |
| 十一章 UI/UX 约束 12/18/19 | 统一空状态插图；列表页支持搜索+分页+重置；表单 rules 校验必填标红 |
| 十二条 API 对接规范 | 401/403/409 统一处理语义（本项目错误码不同，仅借语义） |
| 6.15 风控告警思路 | 「频繁小额定投」「异常价格」等检测思路可用于挂单异常标记 |

## 三、必须拒绝的部分（会造成空壳或违背本项目铁律）

| 司南条目 | 拒绝原因 |
|---|---|
| 17 模块 / 209 接口全实现 | 本项目 MVP 锁定 3 模块 34 接口。剩余 15 模块在源站无数据落点 |
| 2.2 司南红 `#C00000` + 鎏金 `#D4A574` | 与 C 端主蓝 `#4a8ff7` 冲突。已定：**后台沿用 C 端令牌** |
| Element Plus 组件库 | C 端是 Vant 4 移动端库；若后台用 EP，两套产品视觉体系割裂 |
| 表前缀 `nft_` / 16 张新表 + 12 张扩展 | 会污染 C 端已跑通的 48 张表。已定：**新表隔离 + override 影子表** |
| 3.8 平台数据清除 | 本项目无此运营诉求，且属不可恢复操作，MVP 不做 |
| 6.11 区块链交互管理 | 源站无 RPC / 合约证据，臆造 —— 违反「禁止臆造」铁律 |
| 金额 Decimal.js 字符串传输 | 本项目口径已定：**单位为分、整型传输**（源站 `amountFormat` 实测），不用 Decimal.js |

## 四、待决策项

详见 Phase 0 提问。核心矛盾：**后台是 PC 桌面还是移动端 Web**——
C 端是移动 H5（390px 基准 + Vant），但运营后台传统在 PC 上操作。
这决定 UI 库选型（Vant vs Element Plus）与布局断点。
