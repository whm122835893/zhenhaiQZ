# 臻海艺术 · 运营后台 页面设计提示词

> 设计师：颜好看 ｜ 面向：前端 Agent
> 前置必读：`/workspace/docs/admin/DESIGN_SYSTEM.md`（组件规范）+ `/workspace/docs/admin/RESPONSIVE.md`（双端差异）+ `/workspace/admin-web/src/styles/admin-tokens.css`（令牌）
> 通用硬约束（每页都适用，不再逐页重复）：
> - 图标只从 `lucide-vue-next@1.0.0` 导入，尺寸 16/20/24，`stroke-width: 1.75`，零 emoji
> - 组件内禁止 `--color-*`，只用 `--admin-*`
> - 金额一律取后端 `xxxYuan` 字段（单位元），前端不再换算
> - 写操作一律带覆盖徽标 + 审计留痕
> - **三个断点**：`<768px` 移动端（底部 TabBar + 卡片流）/ `768~1023px` 平板（底部 TabBar + 单列居中 640px）/ `≥1024px` 桌面（侧边 Rail 200px + 两栏，内容区 1216px）
> - 每页末尾的「双端行为」三段分别写清：移动端（不变）/ 平板 / 桌面
> - 桌面端列表 = 表格形态，列清单见 `RESPONSIVE.md` §4.2；桌面端筛选 = 顶部横排条；桌面端表单 = 居中 Dialog 480px

## 支撑页

### P-00 登录页 `/login`

- **布局**：单列居中。顶部品牌标（Logo，唯一允许的内联 SVG 例外）+ 下方表单卡（`--admin-stat-radius` / `--admin-stat-bg` / `--admin-stat-pad`）。无 Hero、无口号、无插画。页面高不超过一屏，不滚动。
- **组件**：输入框 ×2（账号 / 密码，`--admin-field-*`）、主按钮（底部宽按钮，非固定栏）、错误提示条。
- **Token**：`--admin-field-*` / `--admin-accent` / `--admin-danger-fg` / `--admin-fs-*`
- **交互状态**：Loading 按钮 loading + 表单禁用；Error 用 `code` 分流——`11001` 显示「用户名或密码错误」并保留已填账号，`11002` 显示「账号已停用」，`20000` 显示「系统异常，请稍后重试」；Disabled 未填满时主按钮禁用；Edge 连续 5 次失败后提示「失败次数过多，请稍后再试」。
- **双端行为**：
  - 移动端（<768）：单列满宽，表单卡宽 100%（左右 12px 边距），无框。
  - 平板（768~1023）：表单卡宽 390px 居中，页面底色不变。
  - 桌面（≥1024）：**居中卡片宽 400px**（不铺满 1216px——登录页是单任务页，铺满会让输入框行长失控），卡片下方给「使用管理员账号登录」一行辅助说明。左侧不放 Rail 插画/品牌墙（会变成品牌页，违反 Product 寄存器）。

### P-00B 工作台 `/dashboard`

> P0 规则：后台首屏**直接是数据与待办**，不做大标题 + 副标题 + CTA 的 Hero。

- **布局**（自上而下，纵向滚动）：
  1. NavBar「工作台」，右侧无操作（观察者角色在此页显示只读徽标）
  2. 待办区：最多 3 条（`--admin-card-*`），按角色渲染——ops 看「版权待审 3 条」、reviewer 看「版权待审 3 条」、support 看「未实名 35 条」、viewer 无待办区
  3. 指标区：2 列栅格摘要卡（`--admin-stat-*`），固定 6 张——总用户 36 / 已实名 1（占比 2.8%）/ 藏品总数 5 / 在售挂单 10 / 累计成交 10 / 累计成交额（元）
  4. 分布列表：藏品成交排行（横向条形，5 个藏品）、成交价区间分布（柱状）
- **组件**：StatCard ×6、ListCard（待办）、横向条形图。
- **Token**：`--admin-stat-*` / `--admin-card-*` / `--admin-fg-*`
- **交互状态**：Loading 每个指标卡独立骨架；Empty 依赖表 0 行的指标卡置灰并显示依赖表名 + 行数，**不显示 0**；Error 单卡失败只该卡显示重试；Disabled 只读角色全页无写入口（viewer）。
- **双端行为**：
  - 移动端（<768）：图表禁用 tooltip，改为点选高亮 + 数值直接标在条形右侧；不画折线图（PRD §9.3：样本量不足）。指标卡 2 列。
  - 平板（768~1023）：形态同移动端，指标卡改 3 列（640px 内容宽下 3 张每张 200px，24.96px 数值不溢出）；图表仍禁 tooltip。
  - 桌面（≥1024）：**指标卡 3 列**（≥1280 为 4 列），数值档 28px；图表区 2 列并排（各最小宽 320px），容器高 260px（≥1280 为 320px）；**恢复 hover tooltip**（桌面有精确指针）；**仍不画折线**——PRD §9.3 的样本量门槛不因断点改变（成交记录 10 条 / 用户 36 条），屏幕变宽只让假趋势看起来更专业。替代物：横向条形图 + 数值直标 + 占比、成交价区间直方图、用户活跃分布表。

### P-00C 无权限页 `/403`

- **布局**：页面级空态（`--admin-empty-*`），图标 `ShieldAlert` 24px。文案区分两种情况：路由级无权限「当前角色无此页面访问权限」/ 接口级 403「当前角色无此操作权限」，并展示当前角色名。底部给「返回工作台」。
- **双端行为**：
  - 移动端（<768）：同形态，无变体。
  - 平板（768~1023）：同形态，无变体。
  - 桌面（≥1024）：同形态，无变体。空态文案宽度不变（`--admin-empty-desc-max-w: 300px`），居中于主内容区。

## 模块一 · 商品与藏品管理（items 5 / nfts 16）

### P-01 藏品列表 `/items`

- **布局**：
  1. NavBar「藏品管理」，右侧 `Search` 图标（展开搜索条，非独立页）
  2. 状态快速筛选 chip 横排可横滑：全部 / 在售（含历史值 `1`）/ 已售罄 / 预热中 / 全部隐藏
  3. 脏数据提示条（`--admin-surface-tint` 底）：「`items.status` 存在 3 种取值，`1` 已按「在售」归一」，可 dismiss
  4. 列表卡 ×5（`--admin-card-*`）
- **列表卡 L1 三字段**：主标识 = 藏品名（臻海蓝卡）／编号 = `#839848`（等宽）／关键值 = 售价 `￥3.88`。状态标签用归一后文案（在售 / 已售罄），原始值 `1` 作为副标弱化处理。
- **L2 就地展开 8 项**：库存、已售、作者、版权关联、是否推荐、是否热门、内容完整度、创建时间。
- **操作**：卡内「更多」→ ActionSheet（上下架 / 编辑内容 / 改推荐标记 / 查看覆盖历史 / 还原）。上下架为高频单操作，**同时挂左滑**。
- **组件**：SearchFilter、ListCard ×5、StatusTag、ActionSheet、脏数据提示条。
- **Token**：`--admin-card-*` / `--admin-tag-*` / `--admin-filter-chip-*` / `--admin-sheet-*` / `--admin-override-badge-*`
- **交互状态**：Loading 首屏 3 张骨架卡；Empty 筛选无结果型空态 + 「清除筛选」；Error 列表区内嵌错误条 + 重试；Disabled `viewer` / `reviewer` 角色隐藏所有写操作项（ActionSheet 只剩「查看详情」）；Edge 藏品名 2 行截断。
- **双端行为**：
  - 移动端（<768）：同形态（卡片流 + L1 三字段 + L2 展开 8 项）。左滑在 ≥768px 鼠标环境下同时提供 hover 图标按钮。
  - 平板（768~1023）：同移动端，筛选 chip 横排可横滑，内容宽上限 640px。
  - 桌面（≥1024）：**改表格形态**，8 列固定顺序：藏品名 / 编号 / 状态 / 售价 / 库存 / 已售 / 作者 / 创建时间。行尾操作列 160px：**「上下架」文字按钮（高频）+「更多」图标**（编辑内容 / 改推荐标记 / 查看覆盖历史 / 还原）。无左滑、无 L2 展开、无卡内「更多」。**「上下架」在移动端是左滑主操作，桌面端放行尾是因为它是列表里唯一高频操作。** 筛选改顶部横排条：搜索框 320px + chip（全部 / 在售 / 已售罄 / 预热中 / 全部隐藏，5 个 chip 中前 4 个直接可见，5th 进「更多筛选」下拉）。脏数据提示条在桌面端同样显示（数据事实与断点无关）。
- **角色裁剪**：`item:write` 缺失时不渲染写操作（不是置灰）。

### P-02 藏品详情 `/items/:iid`

- **布局**：NavBar「藏品详情」+ 返回；顶部藏品头卡（图 56px + 名 + 编号 `#839848` + 状态标签 + 售价 `￥3.88`）；下方 Tab ≤4：**概览 / 内容 / 交易 / 审计**。
- **Tab 内容**：
  - 概览：DL——作者（JOIN `item_authors`，臻海艺术 / 闹翻天）、作品数（**以实时统计为准**，字段 `works_count` 偏差时给提示）、库存、已售、是否推荐/热门、创建时间
  - 内容：图文详情。4/5 藏品 `content` 为空 → 区块级空态「该藏品未录入图文详情」+ 「去编辑」入口；有内容时默认折叠到 96px
  - 交易：挂单数、成交记录数、最近成交价（取 `nft_trade_logs`）
  - 审计：AuditTimeline（`GET /admin/item/:iid/audit`）
- **组件**：DetailTabs、定义列表 DL、AuditTimeline、区块级空态、StatusTag。
- **Token**：`--admin-tab-*` / `--admin-dl-*` / `--admin-timeline-*` / `--admin-empty-*`
- **交互状态**：Loading Tab 内 3 行骨架；Empty 内容 tab 区块空态 + 去编辑；Error 单 tab 内错误条，不整页失败；Disabled 只读角色无「去编辑」；Edge 作者 `works_count=3` 与实际 1 个不符时显示「字段值 3，实时统计 1」双值提示。
- **双端行为**：
  - 移动端（<768）：Tab ≤4 永不滚动；权限裁剪后仅剩 1 个 tab 时隐藏 Tab 条。
  - 平板（768~1023）：同移动端。
  - 桌面（≥1024）：**Tab 保留 ≤4 不变**（工作记忆上限与屏宽无关）。DL 改**双列并排**（左列 label 120px 固定，右列 value，字段两两成对），`--admin-pc-form-label-side-w: 120px`。交易 tab 的挂单数 / 成交记录数 / 最近成交价三项在桌面端并排成 3 张小指标卡（横向）。内容 tab 的长文默认**不折叠**（桌面有纵向空间，96px 折叠反而制造多余点击）。
- **角色裁剪**：`reviewer` 无「交易」tab。

### P-03 藏品编辑（底部 FormSheet，非独立路由）

- **布局**：底部半屏 sheet（`--admin-form-max-h: 76vh`），标题「编辑藏品 · 臻海蓝卡」，副说明「写入将标记为后台覆盖值，不影响 C 端读取」。字段：状态（单选）/ 售价（数值 + 单位后置）/ 是否推荐 / 是否热门 / 图文详情（多行）。label 在输入框上方。
- **覆盖标识**：已被覆盖过的字段，label 右侧挂 `--admin-override-badge-*` 徽标「已覆盖」，字段下方给「还原」入口。
- **组件**：FormSheet、底部操作栏（1 主「保存」+ 1 次「取消」）。
- **Token**：`--admin-field-*` / `--admin-form-*` / `--admin-override-badge-*` / `--admin-footer-*`
- **交互状态**：Loading 保存中按钮 loading 且 sheet 不可 dismiss；Error 字段级错误紧贴字段下方；`14009` 写冲突提示刷新重试；`14003` toast 不跳登录；Disabled 无 `item:write` 时不渲染入口（不是打开后禁用）；Edge 售价输入超 8 位时截断并提示。
- **双端行为**：
  - 移动端（<768）：键盘弹起时提交栏贴键盘顶；ActionSheet 形态。
  - 平板（768~1023）：底部 FormSheet 宽度跟随内容区（640px 上限内），仍居中。
  - 桌面（≥1024）：**改居中 Dialog 480px**（`--admin-pc-dialog-w`），字段 label 移到左侧（`--admin-pc-form-label-side: 1`），label 宽 120px；字段间距 20px（`--admin-pc-dialog-field-gap`）。保存/取消在 Dialog 底部 footer，右对齐（不是通栏主按钮）。售价字段组旁边给「= 49900 分 / ￥499.00」实时回显（PRD 附录 S7 场景，桌面端同样保留——这是防错不是防窄屏）。

### P-04 版权审核队列 `/copyrights`（reviewer 主场）

- **布局**：NavBar「版权审核」；顶部关联诊断说明条（`--admin-tag-anomaly-bg` 底）：「当前关联基于名称字符串匹配，可靠性有限」；列表卡 ×6。
- **列表卡 L1 三字段**：主标识 = 版权名（脏值如 `1` 原样显示并标红提示「名称为无效占位值」）／编号 = 版权 ID／关键值 = **关联诊断结论**（「已匹配 · 臻海蓝卡」或「关联异常：未找到同名藏品」）。
- **L2 就地展开**：缩略图、排序值 `sort`、审核状态、审核人、审核时间、驳回理由。
- **操作**：左滑 = 通过（绿）/ 驳回（红）双操作；「更多」→ 查看详情。
- **组件**：ListCard ×6、StatusTag、诊断说明条、双操作左滑。
- **Token**：`--admin-card-*` / `--admin-tag-*` / `--admin-danger-*` / `--admin-card-swipe-*`
- **交互状态**：Loading 3 张骨架；Empty 全审完时显示「当前无待审版权，共 6 条已全部处理」；Error 内嵌重试；Disabled 无 `copyright:write` 时左滑操作不渲染，只可查看；Edge name 为 `1` 的记录额外标红（PRD AC-11）。
- **双端行为**：
  - 移动端（<768）：左滑是主路径；≥768px 同时提供卡内「通过 / 驳回」文字按钮（因为在 PC 上左滑不可发现）。
  - 平板（768~1023）：同移动端，卡内「通过 / 驳回」文字按钮保留。
  - 桌面（≥1024）：**改表格形态**，7 列：版权名 / 版权 ID / 缩略图 / 关联藏品 / 审核状态 / 审核人 / 审核时间。**行尾操作列 160px：「通过」文字按钮（主色）+「驳回」文字按钮（危险文字色）**——审核是本模块唯一主任务，两个动作必须同时可见，不需要点「更多」。「通过」是高危吗？不是，走 ActionSheet 级确认即可（不要求理由）；「驳回」走**二级高危 Dialog**（必填理由 + 影响面面板）。缩略图 56px 常驻一列（不再是 L2 展开项）——审核员要靠图认版权。诊断说明条在桌面端同样显示。

### P-05 版权详情与裁决 `/copyrights/:id`

- **布局**：NavBar + 返回；头卡（缩略图 + 版权名 + 审核状态标签）；分组：基本信息（DL）／关联藏品（匹配结果显示，异常时给「关联异常」说明 + 治理入口）／审核结论（通过 / 驳回，驳回必填理由）。
- **操作**：底部固定操作栏，1 主「提交审核结论」+ 1 次「取消」。驳回时理由为必填（`--admin-danger-reason-h`），不填无法提交（PRD AC-12）。
- **组件**：DL、StatusTag、FooterBar、表单字段（理由）。
- **Token**：`--admin-dl-*` / `--admin-danger-*` / `--admin-footer-*`
- **交互状态**：Loading 提交中按钮 loading；Error `11006`「参数值非法（remark 未填）」提示紧贴理由框；Disabled 已审核记录所有操作禁用并显示审核人与时间；Edge 版权名过长 2 行截断。
- **双端行为**：
  - 移动端（<768）：同形态；操作栏随内容宽居中（390px 内），不跨满屏。
  - 平板（768~1023）：同移动端，操作栏居中不跨满屏。
  - 桌面（≥1024）：**底部固定操作栏改为右侧 320px 摘要栏底部**（不是贴屏底通栏）——贴屏底通栏在 1216px 宽下会变成一条横贯屏幕的按钮，与「提交审核结论」的局部性不符。摘要栏常驻：版权名 / 状态 / 审核人 / 审核时间 / 关联诊断结论，操作按钮在栏底。驳回理由字段在桌面端为 480px 宽 Dialog 内的多行框（必填校验不变）。

## 模块二 · 二级市场监控（nft_sell_orders 10 / nft_trade_logs 10）

### P-06 挂单监控列表 `/market/sell-orders`

- **布局**：NavBar「二级市场」；Tab ≤4：**挂单（10）/ 成交（10）**；挂单 tab 下方异常预警条（`--admin-tag-anomaly-bg`）：「命中疑似批量挂单：2 个卖家在售挂单数超阈值（最高 5 条，阈值 3 条），共 8 条挂单」。**预警文案必须由实际命中项动态生成**，不得硬编码任何数值；当前数据下「异常低价」规则不命中，该标签不应出现。
- **列表卡 L1 三字段**：主标识 = 藏品名 + NFT 编号／编号 = 挂单 ID／关键值 = 挂单价 `￥5.00`（等宽，千分位）。状态标签：在售 / 已下架 / 异常。
- **L2 就地展开 8 项**：卖家 ID、挂单时间、最近成交价、价差比、异常标记、备注、藏品缩略图、更新时间。
- **操作**：左滑 = 强制下架（红，高危）；「更多」→ 标记异常 / 添加备注 / 查看详情。
- **组件**：DetailTabs、ListCard ×10、异常预警条、StatusTag、ActionSheet。
- **Token**：`--admin-card-*` / `--admin-tag-anomaly-*` / `--admin-card-swipe-danger-bg` / `--admin-danger-*`
- **交互状态**：Loading 3 张骨架；Empty 筛选无结果型；Error 内嵌重试；Disabled 无 `nft:write` 时强制下架不渲染（`support` 只有标记异常与备注权限）；Edge 价差比 >1000% 时截断为「>1000%」。
- **双端行为**：

- **折叠按钮**：Rail 底部，lucide `PanelLeftClose` / `PanelLeftOpen` 20px，热区 44×44。
